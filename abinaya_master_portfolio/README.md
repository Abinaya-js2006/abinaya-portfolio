# Abinaya JS — Master Portfolio

A responsive, dark premium portfolio website for a Full-Stack Developer / AI-ML Enthusiast.

## Run it
1. Extract this ZIP file.
2. Open the `abinaya_master_portfolio` folder.
3. Double-click `index.html` to preview it in your browser.

For local development, you can also use VS Code with the Live Server extension.

## Before publishing
- Replace `your.email@example.com` in `index.html` and `script.js` with your real email address.
- Add your LinkedIn URL in the links marked `href="#"`.
- Add your actual resume PDF and update the hero button if you want a direct download button.
- Upload a profile photo if you want one. The current hero uses an AJ initials illustration as a placeholder.
- Check the internship dates, project descriptions, CGPA, certifications, and hackathon wording for accuracy.
- Replace general GitHub profile links with each exact repository where available.
- Add certificate links or images only for certificates you actually hold.

## Files
- `index.html` — content and page structure
- `style.css` — dark theme, responsive layout and animations
- `script.js` — mobile navigation, skill filters, scroll reveal and demo contact form

## Contact form
The current form uses a mailto flow and does not store or send data to a server. To make a production contact form, connect a trusted form service or build a backend.
